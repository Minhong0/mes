# 시뮬레이터용 프로파일 데이터

`tools/import_excel.py`가 부트캠프 원본(`data/raw/`)에서 자동으로 만듭니다. 직접 고치지 말고 스크립트를 다시 실행하세요.

| 파일 | 내용 | 건수 |
| --- | --- | --- |
| `downtime_events.csv` | 2025년 10월 설비 정지 기록 (날짜, 설비, 비가동 대분류·소분류 코드, 정지 시간) | 220 |

설비 시뮬레이터는 이 파일로 두 가지를 정합니다.

- **얼마나 자주 멈출지**: 설비별 정지 횟수와 가동 시간으로 평균 정지 간격을 구합니다. 예를 들어 CNC03은 (23일 × 960분 − 정지 3,388분) ÷ 66건 ≈ 283분 가동마다 한 번 멈춥니다.
- **왜, 얼마나 오래 멈출지**: 그 설비의 과거 정지 한 건을 무작위로 골라 사유와 시간을 그대로 씁니다.

원본의 한글 사유는 코드(`data/master/common_codes.csv`의 `DT_CAT`, `DT_SUB`)로 바꿔 담았고, 거래처 등 다른 정보는 넣지 않았습니다.
